Un objet qu’on laisse tomber

Les formules du mouvement uniformément accéléré

Les corps en chute libre ont un mouvement uniformément accéléré (MUA). Nous pouvons donc utiliser les formules que tu as apprises dans la leçon 1, en remplaçant l’accélération aa par gg.

N’oublie pas la convention : une direction vers le bas est négative et une direction vers le haut est positive.

vf=vi+gtv_{f} = v_{i} + gt

Un objet qui part du haut

Nous pouvons décrire la chute libre par deux problèmes typiques. Le premier : tu laisses tomber un objet à partir d’une certaine hauteur. Le second (un objet lancé vers le haut) est présenté au chapitre suivant.

Image : docx-image-03.png

Schéma d’une balle qu’on laisse tomber : les flèches de vitesse pointent vers le bas et s’allongent pendant la chute

Voici les caractéristiques d’un tel mouvement :

  • l’accélération gravitationnelle est toujours constante et égale à g=−9,81m/s2g = - 9,81\, m/s^{2};

  • la vitesse augmente négativement (la flèche est dirigée vers le bas et s’allonge graduellement);

  • le déplacement est négatif (vers le bas);

  • nous pouvons utiliser les formules des MUA;

  • la seule force qui agit sur la balle est la force gravitationnelle.

Je te montre : un objet qu’on laisse tomber

✏️ Exemple — Un touriste sur la tour de Calgary laisse tomber un objet. La tour a une hauteur de 191 m. Combien de temps l’objet mettra-t-il pour atteindre le sol?

Étape 1 : Données : vi=0v_{i} = 0, d=−191md = - 191\, m, g=−9,81m/s2g = - 9,81\, m/s^{2}.

Étape 2 : Puisque vi=0v_{i} = 0, on a d=12gt2d = \frac{1}{2}gt^{2}, donc t=2dgt = \sqrt{\frac{2d}{g}}.

Étape 3 : t=2dg=2×(−191m)−9,81m/s2t = \sqrt{\frac{2d}{g}} = \sqrt{\frac{2 \times ( - 191\, m)}{- 9,81\, m/s^{2}}}.

Réponse : t≈6,24st \approx 6,24\, s.

✏️ Exemple — Quelle sera la vitesse de l’objet lorsqu’il touchera le sol?

Étape 1 : On utilise vf=vi+gtv_{f} = v_{i} + gt avec t=6,24st = 6,24\, s.

Étape 2 : vf=0+(−9,81m/s2)(6,24s)v_{f} = 0 + ( - 9,81\, m/s^{2})(6,24\, s).

Étape 3 : Vérification avec vf2=vi2+2gd{v_{f}}^{2} = {v_{i}}^{2} + 2gd : vf2=2(−9,81)(−191)≈3747m2/s2{v_{f}}^{2} = 2( - 9,81)( - 191) \approx 3\ 747\, m^{2}/s^{2}.

Réponse : vf≈−61,2m/sv_{f} \approx - 61,2\, m/s (le signe négatif indique que l’objet descend).

💡 À retenir

  • La chute libre est un MUA : on utilise les formules de la leçon 1 avec a=ga = g.

  • Vers le bas = négatif; vers le haut = positif.

  • Quand on laisse tomber un objet, vi=0v_{i} = 0.

  • Le déplacement et la vitesse sont négatifs pendant la descente.

Vérifie ta compréhension

1. Quelle est la vitesse d’un objet en chute libre après 6,0 secondes s’il part du repos?

vf=vi+gt=0+(−9,81)(6,0)≈−59m/sv_{f} = v_{i} + gt = 0 + ( - 9,81)(6,0) \approx - 59\, m/s

2. Debout sur un pont d’une hauteur de 5,2 m, tu laisses tomber un objet. Quelle est la vitesse de l’objet juste avant l’impact à la surface de l’eau?

vf2=0+2(−9,81)(−5,2){v_{f}}^{2} = 0 + 2( - 9,81)( - 5,2), donc vf≈−10m/sv_{f} \approx - 10\, m/s.

3. Tu es debout sur le toit de l’école. Tu laisses tomber un ballon rempli d’eau sur un de tes amis. Combien de temps le ballon prend-il pour tomber si tu te trouves à une hauteur de 26 m de ton ami?

t=2(−26)−9,81≈2,3st = \sqrt{\frac{2( - 26)}{- 9,81}} \approx 2,3\, s
